Week 03 - Advanced Sales Performance Analysis

This project focuses on advanced analysis of the Superstore dataset to evaluate sales performance, profitability, product performance, regional performance, customer segments, discounting, and business trends.

Project Deliverables

1. Dataset - Source Superstore dataset.
2. Python - Data validation and advanced sales performance analysis notebooks.
3. Power BI - Interactive executive dashboard and supporting visualizations.
4. DAX - Documentation of the measures developed for the Power BI analysis.
5. Reports - Business insights and recommendations, project continuity summary, and Power BI dashboard documentation.

Key Analysis Areas
1. Sales and profit performance
2. Category and sub-category profitability
3. Product performance and loss-making products
4. Regional performance
5. Customer segment analysis
6. Discount and profitability analysis
6. Sales and profit trends
7. Business insights and recommendations

Tools

Python | Pandas | NumPy | Matplotlib | Seaborn | Power BI | DAX

This project demonstrates the application of data validation, exploratory analysis, business intelligence, data visualization, and insight-driven reporting in a practical business case.
